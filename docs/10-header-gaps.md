# 10 — Хардкод в шапке и на странице «Источники»

Шапка (`apps/web/src/app/components/Layout/Header`) и страница «Источники»
(`apps/web/src/pages/Sources`) переделаны по макету [`docs/protorypes/sources.html`](protorypes/sources.html).
Часть элементов макета опирается на данные, которых в API и в приложении пока нет — там, где
такого поля не было, элемент захардкожен на фронте (статичный, не бьётся ни в какой бэкенд) либо
не реализован вовсе. Список ниже — что нужно добавить, чтобы убрать хардкод.

## Шапка

- **Аватар пользователя** — реализовано: фото или инициалы текущего пользователя, по клику —
  меню аккаунта, см. [Меню аккаунта и drawer’ы](11-ui-decisions.md#меню-аккаунта-и-drawerы).
- **Иконка закладок** — реализовано: ссылка на `/bookmarks` с тултипом «Закладки» и точкой, если
  в отслеживаемых папках вышли новые главы; та же точка у пункта «Закладки» в футере. См.
  [Закладки](11-ui-decisions.md#закладки).
- **Колокольчик уведомлений** — иконка с индикатором всегда показывает точку (непрочитанное
  захардкожено как «есть»), клик ничего не открывает, только тултип. Нет ни источника
  уведомлений (обновления глав, статус источников), ни компонента-инбокса. `@mantine/notifications`
  в зависимостях уже есть, но это тосты, а не лента уведомлений — для реальной фичи нужен
  отдельный API и UI.
- **Список «Недавние источники» в выпадающем чипе** — в макете дропдаун селектора источников
  делит список на «Недавние» и «Все источники». Приложение не хранит историю посещений источников
  (ни локально, ни на бэкенде), поэтому в реализации остался только один плоский список с
  фильтром по названию — секции «Недавние» нет. Нужно: трекинг последних открытых `sourceId`
  (проще всего — `localStorage`, без похода на бэкенд).
- **Текст в чипе-селекторе** — реализовано честно, без хардкода: подставляется реальный `title`
  источника, если текущий URL — `/source/:sourceId` или `/title/:titleId`, иначе «Все
  источники».

## Страница «Источники»

- **Счётчик тайтлов на источник** (`78 400` и т. п. в макете) — такого поля нет в контракте
  `Source` (`packages/contracts/src/source.ts`). Решили не подставлять произвольные числа на
  карточку источника, раз они ничем не подтверждены — это будет выглядеть как реальная
  статистика, которой нет. Если метрика нужна, добавьте на бэкенде подсчёт тайтлов по источнику
  и поле в `SourceSchema`, тогда карточка сможет её показать.
- **Причина недоступности источника** («таймаут 12 с», «ответ 503», «разметка изменилась» в
  макете) — в `SourceSchema` есть только `status: ok | degraded | down`, без деталей ошибки.
  Баннер про недоступные источники сейчас показывает только их количество и общую фразу, без
  причины по каждому. Нужно поле вида `lastError` / `lastCheckedAt` в ответе `/sources`.
- **Повтор проверки конкретного источника** — в макете у каждой недоступной карточки есть кнопка
  «Повторить». Отдельного эндпоинта для перепроверки одного источника нет, поэтому реализована
  только массовая проверка — кнопка «Проверить все» в баннере, которая делает `refetch()` всего
  списка `/sources`. Нужен точечный эндпоинт (например, `POST /sources/:id/recheck`), если важно
  дёргать по одному.
- **Кнопка «Предложить источник»** в пустом состоянии поиска — из макета убрана: нет формы или
  эндпоинта, куда такое предложение отправлять.
- **Переключатель «Показывать 18+»** — из шапки ушёл в настройки («Общие» → «Контент 18+»): две
  серверные настройки `showAdultSources` и `hideAdultTitles` в `user_settings`, см.
  [11](11-ui-decisions.md#контент-18).

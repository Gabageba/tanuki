# 05 — Фронтенд

## Структура

```
apps/web/src/
├── app/
│   ├── router.tsx              # react-router, ленивые чанки по маршрутам
│   ├── providers.tsx           # Mantine, QueryClient, i18n, ErrorBoundary
│   └── theme.ts                # тема Mantine, тёмная по умолчанию
├── pages/
│   ├── Home/                   # продолжить чтение + обновления библиотеки
│   ├── Catalog/                # список тайтлов источника, фильтры
│   ├── Search/                 # мультипоиск
│   ├── Manga/                  # карточка тайтла, ветки, список глав
│   ├── Reader/                 # читалка
│   ├── Library/                # сохранённое, история, загрузки
│   └── Settings/
├── features/
│   ├── reader/                 # ядро читалки — самая объёмная часть
│   ├── library/
│   ├── downloads/
│   └── sources/
├── entities/
│   └── manga/                  # карточки, бейджи, форматтеры
├── shared/
│   ├── api/                    # клиент + хуки TanStack Query
│   ├── db/                     # схема Dexie
│   ├── ui/                     # обёртки над Mantine
│   ├── hooks/
│   └── lib/
└── styles/
    ├── _tokens.scss
    └── global.scss
```

Слои — упрощённый FSD. Правило одно и оно линтится: `shared` ← `entities` ← `features`
← `pages` ← `app`. Импорты вверх по слоям запрещены `no-restricted-imports`.

## Состояние

Три хранилища с непересекающимися зонами ответственности:

| Что                                                  | Где                   | Почему                                                        |
| ---------------------------------------------------- | --------------------- | ------------------------------------------------------------- |
| Данные с сервера (каталог, тайтлы, главы)            | **TanStack Query**    | Кеш, ретраи, инвалидация, дедупликация запросов — всё готовое |
| Состояние читалки (режим, зум, текущая страница, UI) | **Zustand**           | Меняется часто, ререндеры должны быть точечными               |
| Библиотека, история, прогресс, офлайн-главы          | **Dexie (IndexedDB)** | Переживает перезагрузку, работает офлайн, это источник истины |
| Фильтры каталога                                     | **nuqs (URL)**        | Шарится ссылкой, работает кнопка «назад»                      |

Прогресс чтения пишется **в Dexie немедленно**, и отдельным фоновым процессом
синхронизируется с сервером. Не наоборот. Сеть в метро отваливается, прогресс теряться
не должен.

### Схема Dexie

```ts
db.version(1).stores({
  library: '&id, sourceId, addedAt, lastReadAt',
  progress: '&[mangaId+branch], mangaId, updatedAt, syncedAt',
  history: '++id, mangaId, readAt',
  downloads: '&[mangaId+chapterId], mangaId, status, downloadedAt',
  mangaCache: '&id, cachedAt', // метаданные для офлайн-просмотра
});
```

`syncedAt` в `progress` — маркер для фоновой синхронизации: всё, где `updatedAt >
syncedAt`, уходит на сервер батчем.

## Читалка

Это ядро продукта. Всё остальное — обвязка вокруг неё. Пишется полностью вручную,
Mantine здесь используется только для оверлея настроек.

### Режимы

| Режим                                  | Для чего                           | Приоритет                                    |
| -------------------------------------- | ---------------------------------- | -------------------------------------------- |
| **Вертикальный непрерывный (webtoon)** | Манхва, корейские/китайские тайтлы | **P0** — для RU-аудитории это основной режим |
| Постранично RTL                        | Классическая японская манга        | P0                                           |
| Постранично LTR                        | Комиксы, часть переводов           | P1                                           |
| Разворот (2 страницы)                  | Планшеты, ландшафт                 | P2                                           |

Вертикальный режим идёт первым не по алфавиту: значительная доля того, что читают на
русских источниках — манхва, а её читают только скроллом.

### Технические требования

- **Виртуализация.** Глава может быть 200+ страниц по 2 МБ. В DOM держим окно ±3
  страницы, остальное — плейсхолдеры фиксированной высоты (отсюда важность `width`/
  `height` из API).
- **Prefetch.** Следующие 3 страницы грузятся заранее через `<link rel="prefetch">` или
  `new Image()`. При переходе на следующую главу — префетч первых 2 страниц следующей.
- **Резервирование места.** Плейсхолдер той же высоты, что и картинка, иначе скролл
  прыгает при подгрузке. Самый заметный дефект чтения на мобильном.
- **Жесты.** Pinch-zoom, double-tap для зума, свайп между страницами, тап по зонам
  (левая треть / правая треть / центр = меню). Реализуется через Pointer Events, не через
  библиотеку — готовые решения плохо дружат с виртуализацией.
- **Клавиатура.** `←`/`→`, `Space`/`Shift+Space`, `Home`/`End`, `F` — фуллскрин, `M` —
  сменить режим. Через `useHotkeys` из Mantine.
- **Сохранение прогресса.** Debounce 1 секунда, запись в Dexie. При выходе из читалки —
  немедленный flush.
- **Автоскрытие UI.** Панели прячутся через 3 секунды бездействия (`useIdle` из Mantine),
  возвращаются по тапу в центр.
- **Wake lock.** `navigator.wakeLock` — экран не должен гаснуть посреди главы.
- **Плавный переход между главами.** Долистал до конца → следующая глава подгружается
  в тот же скролл-контейнер без выхода в меню.

### Настройки читалки

Хранятся в Dexie, применяются мгновенно: режим, направление, отступы между страницами,
ширина контента (для webtoon на десктопе), яркость (CSS-фильтр поверх), цвет фона
(чёрный / серый / бумага), инвертирование, качество изображений (для экономии трафика),
предзагрузка (0–10 страниц).

## Производительность

Целевые метрики на среднем Android (Snapdragon 6-го класса, 4G):

| Метрика                        | Цель              |
| ------------------------------ | ----------------- |
| LCP на каталоге                | < 2.5 с           |
| Время до первой страницы главы | < 1.5 с           |
| Скролл в webtoon-режиме        | стабильные 60 fps |
| Размер основного бандла        | < 200 КБ gzip     |

Что для этого делаем: код-сплит по маршрутам, `@mantine/core` через модульные импорты,
`content-visibility: auto` на карточках каталога, `loading="lazy"` + `decoding="async"`
на обложках, AVIF/WebP с фолбэком, `IntersectionObserver` для бесконечной ленты.

## Интернационализация

Русский — основной и дефолтный язык. Английский — вторым, ради контрибьюторов.
`i18next` + `react-i18next` (те же пакеты, что в `gabageba-ui`). Даты — через `Intl`,
а не Luxon: одна библиотека экономится, а форматирование дат тут тривиальное.

Отдельно: названия тайтлов и жанров **не переводим** — они приходят от источника уже на
русском.

## Доступность

Читалка — это в первую очередь текст и картинки, но базовое соблюдать обязательно:
навигация с клавиатуры по всем маршрутам, видимый фокус, `alt` на страницах
(«Страница N из M»), `prefers-reduced-motion` отключает анимации переходов,
контраст AA в обеих темах. `eslint-plugin-jsx-a11y` уже в конфиге.

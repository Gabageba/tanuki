# Скачивание глав и офлайн

Статус: **Реализуется** · 2026-10-14 — часть 1 из 2 готова (этапы 1–5 и UI этапа 6 без обновления,
установки и iOS)

2026-11-10 — из части 2 реализованы обновление по подтверждению (T1 + T2), отложенная установка
(I1) и действия в меню аккаунта; проверены две версии SW с очередью скачивания в Chromium.

Задача: `offline-downloads` · ветка `feat/offline-downloads` · песочница `/playground/offline-downloads`

## Зачем

На странице тайтла всё, что связано со скачиванием, сейчас заглушки: иконка у главы и «Скачать все»
ничего не делают, плашка «Скачано 42 гл. · 1.8 ГБ» захардкожена и видна у любого тайтла. Рядом в
меню «…» висят «Обновить» и «Поделиться» без обработчиков ([12-todo](../12-todo.md#страница-тайтла)).

Без офлайна от скачивания нет толку, поэтому задача забирает всю Фазу 4 роадмапа
([08](../08-roadmap.md#фаза-4--pwa-и-офлайн), [06](../06-pwa-offline.md)). Офлайн нужен
авторизованному пользователю, который читает в метро, в самолёте, в поезде.

**Удача** — критерий из роадмапа: скачали 10 глав, включили авиарежим, открыли приложение
(в том числе с холодного старта), прочитали все 10, а после появления сети прогресс оказался на
сервере.

**Остаётся как есть:** серверная модель закладок и прогресса (никакого local-first), подпись `/img`,
вход по сессии в httpOnly cookie.

## Скоуп

- **Входит:**
  - меню «…» тайтла: убрать «Обновить», сделать «Поделиться»;
  - скачивание: одна глава, «Скачать все» с выбором (все / непрочитанные / диапазон), очередь в
    Dexie, последовательная загрузка в SW, прогресс, докачка после закрытия вкладки, автоповтор,
    пауза всей очереди, перестановка порядка;
  - состояния скачивания в `ChaptersList`, на странице тайтла и в читалке;
  - реальная плашка «Скачано N гл. · X МБ» на тайтле;
  - страница `/downloads`: очередь, скачанные тайтлы и главы, удаление главы, тайтла и всего;
  - «Профиль → Данные → Удалить скачанные главы»: рабочая строка;
  - офлайн-чтение: читалка берёт скачанную главу из кеша и онлайн, и офлайн;
  - вход без сети по последнему известному пользователю;
  - работа без сети: `/downloads`, страница скачанного тайтла, закладки и главная из кеша;
    каталог источника и поиск показывают скачанное (см. сценарий ниже); остальное по таблице
    стратегий 06;
  - очередь прогресса чтения: офлайн-отметки уходят на сервер, когда появляется сеть;
  - индикация офлайна (вид решает песочница);
  - precache app shell, стратегии кеширования по таблице 06, два раздельных кеша картинок;
  - `navigator.storage.persist()` и `estimate()`;
  - `registerType: 'prompt'` и тост «Доступно обновление»;
  - установка: отложенный `beforeinstallprompt`, пункт «Установить приложение» в меню, подсказка
    для iOS при первом скачивании;
  - автоскачивание новых глав в закладках выбранных папок;
  - автоудаление прочитанных скачанных глав;
  - проверка на реальном iOS.
- **Потом:** фоновая загрузка при закрытом приложении (Background Fetch / Periodic Sync), выбор
  качества или ширины страниц для скачивания.
- **Не входит:** синхронизация скачанного между устройствами (скачанное живёт в браузере
  устройства); изменение закладок и папок без сети (офлайн они видны из кеша только для
  чтения, в очередь до появления сети встаёт лишь прогресс чтения); поиск без сети по
  нескачанным тайтлам — каталоги живут на сайтах источников, офлайн ищем только среди
  скачанного.

## Сценарии

### Поделиться тайтлом

1. Страница тайтла → «…» → «Поделиться».
2. Есть `navigator.share` → системный лист с названием тайтла и ссылкой на `/title/:titleId`.
3. Нет `navigator.share` → ссылка копируется (`useClipboard` из `@mantine/hooks`), уведомление
   «Ссылка скопирована». Если пользователь закрыл системный лист (`AbortError`), ничего не
   показываем.

### Скачать одну главу

1. Страница тайтла (или список глав в читалке) → иконка ↓ в строке главы.
2. Глава встаёт в очередь: иконка «в очереди», затем кольцо прогресса.
3. Первое скачивание в браузере: запрашиваем `navigator.storage.persist()`; в Safari без
   установки показываем подсказку iOS про «На экран Домой».
4. Готово → галочка; плашка на тайтле показывает «Скачано 1 гл. · 24 МБ».
5. Клик по кольцу или «в очереди» отменяет загрузку (уже скачанные страницы этой главы
   удаляются). Клик по галочке → меню с пунктом «Удалить скачанную главу». Клик по красной
   иконке ошибки → повтор.

### Скачать главы ветки

1. «Скачать все» в настройках списка глав текущей ветки.
2. Нейтральная модалка: выбор «Все главы» / «Непрочитанные» / «Диапазон» (с главы … по главу …),
   строка «Будет скачано N гл. · свободно X ГБ» (`estimate()`). Уже скачанные и стоящие в очереди
   главы не считаются и не добавляются повторно.
3. «Скачать главы» → главы встают в конец очереди по порядку чтения (от старых к новым), модалка
   закрывается.

### Управлять загрузками

1. Вход: плашка на тайтле (ведёт к этому тайтлу на `/downloads`), меню аватара / мобильное меню,
   «Профиль → Данные».
2. Сверху очередь: текущая глава с прогрессом, ожидающие; «Приостановить загрузки» /
   «Продолжить загрузки»; перестановка порядка (поднять наверх); отмена; повтор ошибок.
3. Ниже скачанные тайтлы: обложка, название, число глав, объём; раскрываются в список глав.
   Удалить главу, удалить тайтл, удалить всё.
4. Клик по главе открывает читалку.

### Читать без сети

1. Пользователь открывает приложение без сети (вкладка или установленная PWA).
2. App shell из precache, `RequireAuth` пускает по сохранённому пользователю.
3. Видна индикация офлайна. Доступны `/downloads`, страница скачанного тайтла (из кеша
   `/titles/:id` и списка глав), закладки и главная (последний ответ из кеша).
4. Открывает главу → читалка берёт страницы из `tanuki-offline-v1`, метаданные из Dexie.
   «Следующая глава» работает, если следующая тоже скачана; иначе в конце главы «Следующая глава
   не скачана».
5. Прогресс пишется в Dexie и при появлении сети уходит на сервер.

### Каталог и поиск без сети

1. Без сети пользователь открывает `/sources` → источник (`/catalog/:sourceId`).
2. Вместо каталога сайта — сетка скачанных тайтлов этого источника (из Dexie `titles` по
   `sourceId`), по дате скачивания, свежие первыми. Фильтры и сортировки каталога скрыты, поле
   поиска по названию остаётся.
3. `/search` без сети ищет по скачанным тайтлам всех источников: подстрока без учёта регистра по
   `name`, `originalNames`, `altNames`; результаты сгруппированы по источникам, как онлайн.
4. Ничего не скачано из источника / ничего не нашлось → `EmptyState` («Из этого источника ничего
   не скачано» / «Среди скачанного не нашлось»).
5. Появилась сеть → каталог и поиск возвращаются к обычному поведению. Онлайн ничего не меняется:
   фильтра «Скачанные» и отметки на карточках нет.

### Автоскачивание и автоудаление

1. Настройки → новая вкладка «Загрузки»: «Скачивать новые главы» с выбором папок закладок
   (`CompactMultiSelect`, пусто — выключено) и «Удалять прочитанные главы» (переключатель).
2. Автоскачивание: при открытии приложения и при событии «новые главы в закладках» (SSE)
   новые главы тайтлов из выбранных папок встают в очередь. Работает, только пока приложение
   открыто, — закрытое не качает.
3. Автоудаление: когда своя отметка прогресса уходит за скачанную главу (глава стала
   прочитанной), её скачанная копия удаляется. Удалённую так главу автоскачивание повторно не
   ставит.

### Обновление и установка

1. Новая версия SW → тост «Доступно обновление» с кнопкой «Обновить». В читалке тост
   не показывается (ждёт выхода из неё). Пока идёт загрузка глав, обновление применяется после
   конца текущей главы.
2. Chromium: `beforeinstallprompt` откладывается; предложение установки появляется после второй
   дочитанной главы. В меню аватара есть «Установить приложение», пока оно не установлено.
3. iOS Safari без установки: при первом скачивании подсказка «Поделиться → На экран Домой» с
   объяснением, что без установки скачанное может пропасть через 7 дней.

## Логика и правила

### Состояния главы

```ts
export const DOWNLOAD_STATUS = {
  QUEUED: 'queued',
  DOWNLOADING: 'downloading',
  DONE: 'done',
  FAILED: 'failed',
} as const;
export type DownloadStatus = EnumLiteralsOf<typeof DOWNLOAD_STATUS>;

export const DOWNLOAD_ERROR = {
  NETWORK: 'network', // повторы исчерпаны при живой сети
  SOURCE: 'source', // источник ответил ошибкой на /pages или страницу
  QUOTA: 'quota', // QuotaExceededError
} as const;
export type DownloadError = EnumLiteralsOf<typeof DOWNLOAD_ERROR>;
```

Нет записи → «не скачана». Переходы:

- нет → `queued` (кнопка, «Скачать все», автоскачивание);
- `queued` → `downloading` (SW взял главу; одновременно качается одна);
- `downloading` → `done` (все страницы в кеше) / `failed`;
- `queued` / `downloading` → нет (отмена; скачанные страницы удаляются);
- `failed` → `queued` (повтор);
- `done` → нет (удаление вручную или автоудаление).

Константы — фронтовые (`apps/web/src/entities/download/models.ts`), в `@tanuki/contracts` не
идут: сервер про загрузки не знает.

### Очередь

- Одна глава за раз, страницы внутри главы последовательно (не параллельно, см. 06).
- Каждая страница — до 3 попыток с паузой (1 с, 3 с, 9 с). После третьей неудачи глава
  `failed` (`network`/`source`), очередь идёт дальше.
- Пропала сеть (`offline`) → очередь ждёт `online` и продолжает с той же страницы, глава в
  `failed` не уходит.
- `QuotaExceededError` → глава `failed` с `quota`, вся очередь встаёт на паузу.
- Пауза всей очереди — флаг в Dexie, переживает перезапуск.
- Порядок — поле `order` в Dexie; «поднять наверх» ставит главу (или все главы тайтла) первыми
  после текущей.
- Подпись `/img` живёт 1 час: SW берёт `/pages` прямо перед началом главы, а если подпись
  истекла посреди главы (403 `INVALID_SIGNATURE`), запрашивает `/pages` заново и продолжает.
- Докачка: при старте приложения `downloading` возвращается в `queued`, и очередь идёт дальше.
  Уже сохранённые страницы не перекачиваются.
- В очередь можно поставить главу любой ветки любого тайтла; дубликат (та же `chapterId`) не
  добавляется.

### Владелец данных

Скачанное привязано к `userId`: база Dexie `tanuki-offline-<userId>`, ключи кеша с `userId` в
префиксе. При выходе ничего не удаляется. Другой пользователь в том же браузере видит только своё.
Вернулся — всё на месте. Очередь чужого пользователя не качается.

### Обратимость и тон модалок

- Удаление одной главы — без модалки, из меню у галочки (перекачать легко).
- «Удалить скачанные главы тайтла» и «Удалить все скачанные главы» — `danger`: в момент, когда
  они нужны (без сети), вернуть их нельзя. Иконка `TrashIcon`.
- «Скачать все» — `neutral`, иконка `DownloadSimpleIcon`.

### Офлайн-вход

`/auth/me` при успехе сохраняется (`localStorage`, ключ последнего пользователя). Сетевая ошибка
(не 401) → `useCurrentUser` отдаёт сохранённого пользователя, `RequireAuth` пускает. 401 при живой
сети → как сейчас, на логин. Сохранённый пользователь удаляется при явном выходе.

### Прогресс офлайн

Отметка, которую не удалось отправить из-за сети, пишется в Dexie (`pendingProgress`, одна запись
на тайтл, последняя побеждает) и отправляется по `online` и при старте. Пока запись висит,
отметка в UI берётся из неё.

## Данные и API

**Сервер не меняется.** Все новые данные локальные.

Dexie (`apps/web`, новая зависимость `dexie`), база `tanuki-offline-<userId>`:

| Таблица           | Ключ        | Поля                                                                                                            |
| ----------------- | ----------- | --------------------------------------------------------------------------------------------------------------- |
| `downloads`       | `chapterId` | `titleId`, `branchId`, `status`, `error?`, `order`, `pagesDone`, `pagesTotal`, `bytes`, `createdAt`, `doneAt?`  |
| `chapters`        | `chapterId` | снимок `Chapter` + `PagesResponse` (страницы с `width`/`height`, `prevChapterId`, `nextChapterId`), `numbering` |
| `titles`          | `titleId`   | снимок `TitleDetails` (для `/downloads` и страницы тайтла офлайн), `coverKey`                                   |
| `queue`           | `id`        | `isPaused`                                                                                                      |
| `pendingProgress` | `titleId`   | тело `useUpdateReadingProgress`                                                                                 |

Cache API:

- `tanuki-offline-v1` — скачанные страницы и обложки скачанных тайтлов по синтетическому ключу
  `/offline/<userId>/<titleId>/<chapterId>/<pageIndex>`. Не вытесняется, чистится только явным
  действием. Запрос из SW идёт с `X-Tanuki-Offline: 1`.
- Обычный кеш картинок (LRU) — обложки и страницы при онлайн-чтении, по таблице 06.
- Кеши API — по таблице 06: `/sources` SWR, `/titles/*` SWR, плюс закладки и главная
  (StaleWhileRevalidate) для офлайн-библиотеки. Каталог и поиск в HTTP-кеш не кладём: офлайн их
  заменяет выборка из Dexie `titles` (поле `sourceId`, названия для поиска).

Подпись `/img` меняется на каждом ответе, поэтому читалка ищет скачанную страницу по
`chapterId/pageIndex`, а не по URL: для главы со статусом `done` она строит страницы из Dexie и
синтетических ключей (их отдаёт SW), онлайн тоже.

Объём: `bytes` главы — сумма `content-length` (или `blob.size`) её страниц; плашка и `/downloads`
суммируют их из Dexie. «Свободно» — `estimate().quota - usage`.

Настройки «Загрузки» (папки автоскачивания, автоудаление) — устройство-зависимые, живут в
локальных настройках (`SETTINGS_STORAGE_KEY`), не в `user-settings` сервера.

Маршрут `ROUTE_PATHS.DOWNLOADS: '/downloads'`; вкладка `SETTINGS_TABS.DOWNLOADS: 'downloads'`.

## Крайние случаи

| Случай                                                   | Что видит пользователь                                                                    |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Браузер без SW / без IndexedDB (приватный режим)         | Кнопок скачивания нет, плашки нет, `/downloads` — `EmptyState` «Скачивание недоступно»    |
| Ничего не скачано                                        | Плашки нет; `/downloads` — `EmptyState` со ссылкой в каталог                              |
| Источник не отдал `/pages` или страницу                  | Глава `failed`, красная иконка, повтор по клику; очередь идёт дальше                      |
| Источник `down`                                          | То же; «Скачать все» доступно, главы падают в `failed`                                    |
| Кончилось место                                          | Глава `failed` (`quota`), очередь на паузе, на `/downloads` объяснение и «Удалить…»       |
| Пропала сеть посреди загрузки                            | Очередь ждёт, прогресс стоит, при сети продолжает                                         |
| Вкладку закрыли посреди загрузки                         | При следующем открытии докачивается с той же страницы                                     |
| Подпись `/img` истекла посреди главы                     | Незаметно: `/pages` перезапрашивается                                                     |
| Глава исчезла у источника после скачивания               | Скачанная копия остаётся, читается; в `/downloads` глава видна, хотя в списке глав её нет |
| Офлайн, глава не скачана                                 | Строка в списке глав приглушена; читалка — `EmptyState` «Глава не скачана»                |
| Офлайн, каталог источника                                | Скачанные тайтлы этого источника; пусто → `EmptyState`                                    |
| Офлайн, поиск                                            | Поиск по названиям скачанных тайтлов, группы по источникам; пусто → `EmptyState`          |
| Офлайн, страница тайтла не в кеше                        | Состояние «Нет сети» (вид решает песочница)                                               |
| Офлайн, следующая глава не скачана                       | В конце главы «Следующая глава не скачана» вместо кнопки перехода                         |
| Офлайн, первый запуск в этом браузере (нет пользователя) | Логин с сообщением «Нет сети»                                                             |
| Сессия истекла, пока был офлайн                          | При появлении сети 401 → логин; скачанное остаётся и вернётся после входа                 |
| Другой пользователь в том же браузере                    | Видит только своё скачанное                                                               |
| iOS Safari без установки                                 | Подсказка при первом скачивании; данные могут пропасть через 7 дней                       |
| 1000+ глав в «Скачать все»                               | Модалка честно показывает объём; в Dexie встают одной транзакцией                         |
| Длинное название тайтла на `/downloads`                  | Обрезается в одну строку (`truncate`)                                                     |
| `navigator.share` нет / пользователь закрыл лист         | Копирование с уведомлением / ничего                                                       |

**Выбранный вариант** — **C2e + D2 + B3 + M2 + Q2 + L4 + E2 + P2 + S2a + N2b + U1 + K·пусто + T1 +
T2 + I1 + H1 + H11** по `/playground/offline-downloads`, подробно —
[11-ui-decisions](../11-ui-decisions.md#скачивание-глав-и-офлайн). Коротко: у главы одна иконка
состояния насыщенного цвета и счётчик страниц, пока качается; на тайтле карточка с прогрессом и
«Открыть загрузки»; модалка — режимы карточками с числом глав; «Загрузки» — вкладки «Очередь»
(перетаскивание) и «Скачанное» (раскрывающийся список); «Нет сети» — бледная золотая полоса под
шапкой со ссылкой «Загрузки», в читалке её нет.

**Где живёт:**

- Страница тайтла: меню «…» (только «Поделиться»), плашка под кнопками (`TitleImageSection`),
  «Скачать все» в `TitleChaptersSettings`, иконка состояния в `ChapterItem`.
- `ChaptersList` получает состояния скачивания и действия — та же логика в читалке
  (`ReaderChapterName`).
- Новая страница `/downloads`: на десктопе и мобилке; вход из меню аватара, мобильного меню,
  профиля и плашки.
- «Профиль → Данные»: строка «Удалить скачанные главы» показывает реальный объём, ссылку
  «Загрузки» и открывает danger-модалку; неактивна, если ничего не скачано.
- Каталог источника и `/search`: без сети показывают скачанные тайтлы той же сеткой карточек,
  без фильтров и сортировок.
- Настройки: новая вкладка «Загрузки» (в `TABS` `pages/Settings/index.tsx`).
- Глобально: индикация офлайна, тост обновления, предложение установки, подсказка iOS.

**Загрузка:** `/downloads` и плашка читают Dexie (ответ мгновенный, скелетона и спиннера нет).
«Скачано» на `/downloads` может быть пустым, но данные локальные: пусто → сразу `EmptyState`.

**Модалки** (добавить в таблицу `docs/11-ui-decisions.md`):

| Модалка                        | Тон       | Иконка               | Кнопка                        |
| ------------------------------ | --------- | -------------------- | ----------------------------- |
| Скачать главы ветки            | `neutral` | `DownloadSimpleIcon` | «Скачать главы»               |
| Удалить скачанные главы тайтла | `danger`  | `TrashIcon`          | «Удалить скачанные главы»     |
| Удалить все скачанные главы    | `danger`  | `TrashIcon`          | «Удалить все скачанные главы» |

**Шрифты:** объёмы и счётчики в списках `/downloads` (`24 МБ`, `3/12`) и проценты — моноширинные.
Фраза «Скачано 12 гл.» на плашке остаётся Golos Text, а число и объём уходят в
`NumericMeta`-подобную разбивку, если плашка становится строкой значений.

**Терминология:**

| Понятие                            | В UI                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------- |
| Сохранить главу на устройство      | «Скачать», «скачанные главы»                                            |
| Экран управления                   | «Загрузки»                                                              |
| Очередь                            | «Очередь»                                                               |
| Приостановить / продолжить очередь | «Приостановить загрузки» / «Продолжить загрузки»                        |
| Нет сети                           | «Нет сети» (не «офлайн-режим»)                                          |
| Обновление SW                      | «Доступно обновление», «Обновить» (тост) / «Обновить приложение» (меню) |

**Референсы:** загрузки в Tachiyomi/Mihon (очередь с перестановкой, иконка состояния в строке
главы), офлайн в Spotify / YouTube Music (страница загрузок и пометка доступного без сети).
**Антиреференс:** модалка подтверждения на каждую главу; офлайн, где всё недоступное просто
белый экран.

## Вопросы к макетам

1. **Иконка состояния в строке главы** — пять состояний (↓, в очереди, кольцо прогресса,
   галочка, ошибка), меню у галочки; приглушённая строка «не скачана» в офлайне.
2. **Плашка на тайтле** — вид «Скачано N гл. · X МБ» и «Скачивается 3 из 12»; как выглядит
   ссылкой на `/downloads`.
3. **Модалка «Скачать главы»** — выбор все / непрочитанные / диапазон (`SegmentedControl` или
   `Radio`), поля диапазона, строка объёма и свободного места.
4. **Страница `/downloads`** — очередь (текущая, ожидающие, ошибки, пауза, перестановка: кнопка
   «наверх» или drag) и скачанные тайтлы (карточки или раскрывающийся список); мобилка.
5. **Индикация офлайна** — значок в шапке, полоса под шапкой или тост; `EmptyState` «Нет сети»
   для недоступных блоков; глушить ли тосты ошибок.
6. **Тост обновления, предложение установки, пункт меню, подсказка iOS** — вид и место каждого.
7. **Вкладка настроек «Загрузки»** — папки автоскачивания и автоудаление, плюс объём и ссылка на
   `/downloads`.
8. **Строка «Удалить скачанные главы» в профиле** — как уживаются объём, ссылка и кнопка.
9. **Каталог и поиск без сети** — как объяснить, что показаны только скачанные (заголовок,
   подпись, заметка над сеткой), куда деваются фильтры, пустые состояния.

**Ответы макетов** (2026-10-14):

1. Строка главы — C2e: ↓ / часы / кольцо со счётчиком «12/30» / галочка с меню удаления / красный
   «!» с повтором, значки насыщенными цветами; без сети — D2: строка приглушена, перечёркнутое
   облако.
2. Плашка — B3: карточка с рамкой под кнопками, фраза, объём, полоса прогресса, «Открыть загрузки».
3. Модалка — M2: `Radio.Card` с числом глав, диапазон внутри карточки, строка объёма; не хватает
   места — золотое предупреждение, не запрет.
4. `/downloads` — L4 (вкладки «Очередь» / «Скачанное») + Q2 (перетаскивание, крестик отмены) + L1
   (раскрывающийся список); пусто — E2.
5. Индикация — N2b: полоса под шапкой со ссылкой «Загрузки», в читалке нет; недоступное — U1 с «Открыть загрузки»; тосты
   сетевых ошибок без сети глушатся.
6. Обновление — T1 (тост один раз) + T2 (пункт меню с точкой, пока не применено; на аватаре точки нет); установка — I1
   (тост после второй главы) и пункт меню; iOS — H1 (тост при первом скачивании) + H11 (серый блок
   с акцентной полосой слева на «Загрузках» до «Не сейчас»).
7. Вкладка настроек — S2a: «Автоматически» и «Хранилище» (скачано, свободно, защита от очистки);
   поле папок и полоса свободного места — на всю ширину строки.
8. Профиль — P2: строка «Загрузки» с объёмом и отдельная «Удалить скачанные главы».
9. Каталог и поиск без сети — без заметки (объясняет полоса), фильтры исчезают; пустые состояния
   K·пусто.

## Этапы реализации

1. ✅ **SW-основа (без макетов):** precache app shell, `registerType: 'prompt'`, стратегии по
   таблице 06, два кеша картинок; Workbox-модули в `sw.ts`.
2. ✅ **Хранилище и очередь (без макетов):** `dexie`, `entities/download` (models, база на
   `userId`, хуки чтения через `useLiveQuery`), протокол `postMessage` UI ↔ SW, последовательная
   загрузка, повторы, пауза, порядок, докачка, обновление подписи, `persist()`/`estimate()`.
3. ✅ **Офлайн-вход и прогресс (без макетов):** кеш `/auth/me`, `RequireAuth`, `pendingProgress`.
4. ✅ **Читалка из кеша:** скачанная глава из Dexie + `tanuki-offline-v1`, переход к следующей
   главе офлайн.
5. ✅ **Меню «…» тайтла:** убрать «Обновить», «Поделиться» (без макетов).
6. ◐ **UI по макетам:** `ChapterItem` / `ChaptersList`, плашка, модалка «Скачать главы»,
   `/downloads`, профиль, вкладка настроек, индикация офлайна, тост обновления, установка. Готово
   всё, кроме тоста обновления, установки и подсказки iOS, — они во второй части.
7. **Каталог и поиск без сети** — выборка из Dexie, переключение по `online`/`offline`.
8. **Автоскачивание и автоудаление.** «Новые» главы — по локальной отметке: когда тайтл попадает
   под автоскачивание, на устройстве запоминаются id его глав, позже в очередь встаёт всё, чего в
   этом списке нет (решено 2026-10-14; сервер не меняется, вышедшее до включения не качается).
9. **Проверка:** сценарий «10 глав, авиарежим» в Chrome и на реальном iOS.
10. **docs.**

## Отвергнутые идеи

- **Пункт «Обновить» в меню тайтла** — решили не делать (12-todo).
- **Загрузка из вкладки без SW** — встаёт при уходе со страницы.
- **Background Fetch API** — только Chromium; отложено в «потом».
- **Нормализация URL `/img` в SW или стабильные URL на сервере** — свой ключ
  `chapterId/pageIndex` проще и не трогает контракт.
- **Удаление скачанного при выходе** — храним по `userId`.
- **Проверка объёма до старта по всем `/pages`** — дорого; оценка по `estimate()` и пауза по
  `QuotaExceededError`.
- **Только Wi-Fi** — `navigator.connection` нет в Safari и Firefox.
- **Фильтр «Только скачанные» онлайн и отметка на карточках** — каталог и поиск показывают
  скачанное только без сети.
- **Локальные фильтры (тип, теги, статус) в офлайн-каталоге** — только поиск по названию.
- **Кеш каталога NetworkFirst** — офлайн его заменяет выборка скачанного.
- **Офлайн-доступ к любой ранее открытой странице** — офлайн гарантируем только для загрузок,
  скачанного тайтла, закладок и главной; остальное по стратегиям 06.

# Закладки

Статус: **Реализован** · 2026-10-07
Задача: `bookmarks` · ветка `feat/bookmarks` · песочница `/playground/bookmarks`

## Зачем

Сейчас тайтл некуда сохранить. Если человек нашёл что-то почитать, ему остаётся помнить название
или держать вкладку открытой. Где он читает, видно только по отметкам прогресса внутри конкретного
тайтла. Каркас под закладки в UI уже есть, но он пустой:

- маршрут `/bookmarks` и пункт «Закладки» в футере ведут на заглушку `pages/Bookmarks`;
- иконка закладки в шапке не кликается и подписана «Библиотека — скоро»;
- на странице тайтла стоит неработающий `Select` «Читаю»;
- в читалке есть кнопка-закладка без действия;
- импорт и экспорт закладок в профиле — макеты со статусами `MOCK_BOOKMARK_STATUS`.

Фича для любого вошедшего пользователя: гостей в приложении нет. Удача выглядит так:

- тайтл можно разложить по папкам со страницы тайтла и из читалки;
- в одном месте видно всё сохранённое;
- там же видно, где вышли новые главы с прошлого визита;
- одна закладка покрывает все подтверждённые копии тайтла на разных источниках.

Остаётся как есть: прогресс чтения (`reading_progress`) живёт отдельно от закладок. Удаление
закладки его не трогает, а чтение не меняет папку.

## Скоуп

- **Входит:**
  - модель закладок и папок на сервере;
  - четыре встроенные папки и свои папки (иконка, цвет, флаг «Следить за обновлениями»);
  - страница `/bookmarks`;
  - выбор папки на странице тайтла и в читалке;
  - проверка новых глав (крон + дотяжка) с пометкой «обновился» на карточке;
  - подсветка новых глав в списке глав;
  - метка «в закладках» на карточках каталога и поиска;
  - точка в шапке и футере;
  - счётчики по папкам в профиле;
  - вкладка «Закладки» в настройках для управления папками;
  - модалка выбора папки при склейке тайтлов.
- **Потом (отдельным планом):** импорт и экспорт закладок — из файла и с источника. Сейчас это
  заглушки в `pages/Profile/components/ProfileData`. При реализации MVP `MOCK_BOOKMARK_STATUS`
  заменяется настоящим enum из контрактов. Офлайн-просмотр списка закладок.
- **Не входит:**
  - закладки на страницу внутри главы: прогресс уже запоминает место;
  - автоматическая смена папки по чтению;
  - лента уведомлений (колокольчик) — вынесена в [notifications.md](notifications.md). Снимки глав из этой фичи потом станут её источником.

## Сценарии

### 1. Добавить тайтл в закладки со страницы тайтла

1. Пользователь открывает страницу тайтла. Под «Продолжить» стоит `Select` с плейсхолдером
   «В закладки» и контурной иконкой закладки.
2. Выбирает папку. Тайтл добавлен, `Select` показывает иконку и название папки в её цвете.
3. Если подтверждённая копия тайтла с другого источника уже в закладках, `Select` с самого начала
   показывает её папку. Смена папки действует на всю группу.

### 2. Сменить папку или убрать из закладок

1. В том же `Select` выбирается другая папка, и закладка переезжает сразу.
2. Последний пункт списка — «Убрать из закладок». Он убирает закладку всей группы без модалки и
   показывает тост «Убрано из закладок» с кнопкой «Вернуть», которая восстанавливает всё как было.

### 3. Из читалки

1. В панели читалки `ActionIcon`: не в закладках — серая контурная закладка, в закладках —
   контурная иконка папки её цветом (R2c).
2. Тап открывает `Menu` с теми же пунктами, что `Select` на странице тайтла: папки и «Убрать из
   закладок».

### 4. Посмотреть закладки

1. Точка входа:
   - десктоп — иконка в шапке, теперь это ссылка на `/bookmarks` с тултипом «Закладки»;
   - мобилка — пункт «Закладки» в футере.
   - На обоих стоит точка, если хоть в одной закладке есть новые главы.
2. На странице полоса вкладок-папок со счётчиками: встроенные первыми, затем свои в заданном
   порядке.
3. Под вкладками стоят поиск по названию, сортировка с направлением и переключатель сетка/список,
   ниже — тайтлы с `ListPagination`. Направление выбирается в подвале списка сортировки, как в
   каталоге; при смене сортировки оно сбрасывается на естественное — даты свежими первыми,
   алфавит от «А». Вид общий с каталогом (`viewMode` в настройках): сменил в одном месте —
   поменялся и в другом.
4. Карточка показывает:
   - обложку и название (снимок);
   - где остановился, например «Гл. 1090 из 1093»;
   - пометку «обновился», если вышли новые главы (без числа);
   - иконку источника с «+N», если в группе несколько источников.
5. Клик по карточке ведёт на страницу тайтла на **источнике самой свежей отметки чтения**. Если в
   группе не читали — туда, где добавили.
6. Клик по иконке источника открывает меню остальных источников группы. Пункт меню ведёт на тайтл
   на этом источнике.

### 5. Новые главы

1. Сервер сам, раз в несколько часов, проверяет тайтлы из папок с флагом «Следить за
   обновлениями».
2. Открытие страницы тайтла тоже обновляет снимок его глав.
3. На карточке в `/bookmarks` видно, что тайтл обновился — вышли главы после последнего визита.
   Сколько именно, на карточке не показывается.
4. Человек открывает страницу тайтла. Новые главы в списке помечены точкой у узла (N3), пока
   страница открыта.
   Визит засчитан, пометка на карточке снята.
5. Чтение главы тоже засчитывается как визит.

### 6. Управлять папками

1. Настройки → вкладка «Закладки». Там `GroupedList` папок, как список источников:
   - ручка для перетаскивания (`@dnd-kit`);
   - иконка и название;
   - тумблер «Следить за обновлениями».
2. У встроенных папок можно менять только порядок и флаг. Переименовать или удалить их нельзя.
3. «Новая папка» открывает модалку (тон `neutral`): название, выбор иконки и цвета, флаг.
4. «Переименовать» в меню своей папки открывает ту же модалку.
5. «Удалить» в меню своей папки:
   - папка пуста — модалка `danger` с подтверждением;
   - в папке есть тайтлы — модалка `danger` спрашивает, что с ними сделать: перенести в другую
     папку (`Select`, по умолчанию «В планах») или убрать из закладок.
6. На `/bookmarks` рядом с вкладками стоит ссылка на эту вкладку настроек и быстрое «Новая папка».

### 7. Склейка при подтверждении совпадения

1. Пользователь подтверждает связь двух тайтлов, а они оба в закладках, но в разных папках.
2. Модалка (тон `warning`): «Оба тайтла в закладках — в какой папке оставить?» и выбор из двух
   папок.
3. После подтверждения обе строки переезжают в выбранную папку. В списке группа видна одной
   закладкой.
4. Если связь потом отменить, получатся две закладки в одной папке. Модалки здесь нет.

### 8. Профиль

1. Вкладка статистики в профиле получает блок со счётчиками по папкам.
2. Клик по папке ведёт на `/bookmarks` с этой вкладкой.

## Логика и правила

### Папки

- **Встроенные** — ровно четыре, у каждого пользователя:

  ```ts
  export const BUILT_IN_BOOKMARK_FOLDER = {
    READING: 'reading', // Читаю
    PLANNED: 'planned', // В планах
    COMPLETED: 'completed', // Прочитано
    DROPPED: 'dropped', // Брошено
  } as const;
  ```

  - Название переводится на фронте через `getBuiltInBookmarkFolderLabel(folder, t)` со
    `switch`.
  - Иконка и цвет заданы в коде.
  - Переименовать или удалить нельзя. Порядок и флаг «Следить за обновлениями» менять можно.
  - Флаг по умолчанию: включён у всех, кроме «Брошено».
  - Строки встроенных папок создаются лениво, при первом обращении пользователя к закладкам.

- **Свои** — пользователь создаёт, переименовывает, удаляет и двигает их сам.
  - Иконка выбирается из набора `BOOKMARK_FOLDER_ICON`, цвет — из `BOOKMARK_FOLDER_COLOR`. Оба —
    const-объекты в контрактах. Состав наборов решит песочница.
  - Флаг «Следить за обновлениями» по умолчанию включён.

- **Лимиты:**
  - не больше 20 своих папок;
  - название от 1 до 32 символов после `trim`;
  - название уникально у пользователя без учёта регистра, в том числе против переведённых названий
    встроенных папок на языке пользователя.
  - Число закладок не ограничено.

### Закладки

- **Одна папка на тайтл.** Закладка всегда лежит ровно в одной папке.
- **Ключ — тайтл на источнике** (`titleKey = linkKeyOf(sourceId, url)`, как в `reading_progress` и
  `title_links`). Показ и правки работают на уровне **группы подтверждённых совпадений**
  (`TitleLinksService.listConfirmedGroup`):
  - тайтл считается «в закладках», если в закладках он сам или любая подтверждённая копия;
  - смена папки переносит все строки группы;
  - «Убрать из закладок» удаляет все строки группы;
  - добавление со страницы тайтла, чья группа уже в закладках, невозможно: `Select` уже показывает
    папку.
- **Без автопереходов.** Папку меняет только пользователь. Чтение главы не кладёт тайтл в «Читаю»,
  а дочитывание не кладёт его в «Прочитано».
- **Обратимость:**
  - «Убрать из закладок» обратимо через «Вернуть» в тосте, поэтому идёт без модалки;
  - удаление папки необратимо — модалка `danger`;
  - выбор папки при склейке ничего не теряет, но переносит закладку — модалка `warning`.

### Новые главы

- «Новая глава» — та, что впервые попала в снимок глав тайтла **после последнего визита**
  пользователя в группу.
- **Визит** — открытие страницы тайтла любого источника группы или сохранение прогресса чтения в
  группе.
- Новые главы (`newChaptersCount`) считаются по источнику, на который ведёт карточка (источник
  свежей отметки), и только по ветке этой отметки. Если отметки нет, считается по ветке по
  умолчанию. Число нужно серверу (сортировка «По обновлению», `hasNew`); карточка показывает только
  признак `newChaptersCount > 0`.
- **Первый снимок** тайтла — базовый: его главы новыми не считаются. Иначе тайтл, добавленный
  до первого прохода крона, показал бы все главы новыми.
- Закладки в папках без флага «Следить за обновлениями» не попадают в обход крона, и пометки у
  них нет. Дотяжка при открытии страницы тайтла работает для любого тайтла.
- Точка в шапке и футере горит, пока хоть у одной закладки в отслеживаемой папке есть новые
  главы.

### Куда ведёт карточка

- Цель — источник самой свежей отметки `reading_progress` в группе. Если отметок нет — источник
  самой ранней строки закладки, то есть где добавили.
- Выключенные пользователем источники (`disabled_sources`) целью не становятся, если в группе есть
  другие.

### Недоступный источник

- Снимок названия и обложки хранится в строке закладки, так что карточка рисуется всегда.
- Если в группе не осталось доступных источников, карточка приглушена и подписана:
  «Источник выключен», «Источник недоступен» или «Тайтл не найден на источнике».

  ```ts
  export const BOOKMARK_AVAILABILITY = {
    AVAILABLE: 'available',
    SOURCE_DISABLED: 'sourceDisabled', // выключен в настройках
    SOURCE_DOWN: 'sourceDown', // source_health = down
    TITLE_MISSING: 'titleMissing', // крон получил «не найдено»
  } as const;
  ```

- Такую закладку можно открыть (экран ошибки как сейчас) или убрать.

### Сортировка

Порядок по умолчанию — «По обновлению».

```ts
export const BOOKMARK_SORT = {
  UPDATED: 'updated', // свежая новая глава первой, без новых — по дате проверки
  READ: 'read', // последнее чтение в группе
  ADDED: 'added', // дата добавления
  ALPHABETICAL: 'alphabetical', // по снимку названия
} as const;
```

Поиск — подстрока в снимке названия без учёта регистра.

## Данные и API

Всё хранится на сервере в Postgres, модуль `LibraryModule` из `01-architecture.md`. Dexie и
local-first из Фазы 5 roadmap не делаем. Это идёт вслед за решением, по которому всё приложение
требует вход, а прогресс уже лежит на сервере.

### Таблицы (`apps/api/src/database/schema.ts`)

- `bookmark_folders`
  - `id` uuid, `userId` → users cascade;
  - `builtIn` text `$type<BuiltInBookmarkFolder>()` — null у своих;
  - `name`, `icon`, `color` — null у встроенных;
  - `position` int, `trackUpdates` bool, `createdAt`, `updatedAt`.
  - Уникальные индексы: `(userId, builtIn)` и `(userId, lower(name))`.
- `bookmarks`
  - PK `(userId, titleKey)`;
  - `sourceId`;
  - `titleId` — полный `Title.id`, для перехода;
  - `folderId` → bookmark_folders, `restrict`: перенос при удалении папки делает сервис;
  - снимки `name`, `coverUrl`;
  - `visitedAt` — последний визит, общий для группы: пишется во все её строки;
  - `createdAt`, `updatedAt`.
  - Индекс `(userId, folderId)`.
- `title_chapter_snapshots` — общая для всех пользователей.
  - PK `titleKey`;
  - `sourceId`, `titleId`, `checkedAt`, `lastError`;
  - `missing` bool — источник ответил «не найдено».
- `title_chapters_seen` — общая.
  - PK `(titleKey, chapterId)`;
  - `branchId`, `chapterVolume`, `chapterNumber`;
  - `firstSeenAt`;
  - `baseline` bool — глава из первого снимка.

### Крон и дотяжка

- `BookmarkUpdatesService`, `@Cron` раз в 3 часа (интервал — в конфиге, как у `SourceProbeModule`).
- Обходит уникальные `titleKey` из закладок в папках с `trackUpdates`.
  - Каждый тайтл запрашивается один раз, сколько бы пользователей его ни сохранили.
  - Запросы идут через `ResilienceModule` (лимитер и брейкер); источники в статусе `down` он
    пропускает.
  - Порядок — сначала давно не проверенные.
  - Каждая новая `chapterId` пишется в `title_chapters_seen`.
- **Дотяжка:** запрос глав тайтла со страницы тайтла пишет снимок тем же кодом. Кеш глав в Valkey
  не мешает: снимок пишется из того, что ушло клиенту.

### Контракты (`packages/contracts/src/bookmark.ts`)

- Enum'ы:
  - `BUILT_IN_BOOKMARK_FOLDER`
  - `BOOKMARK_FOLDER_ICON`
  - `BOOKMARK_FOLDER_COLOR`
  - `BOOKMARK_SORT`
  - `BOOKMARK_AVAILABILITY`
- Схемы:
  - `BookmarkFolder` — `id, builtIn, name, icon, color, position, trackUpdates, count, newCount`;
  - `BookmarkItem`;
  - `TitleBookmark`.
- Коды ошибок: `bookmarkFolderLimit`, `bookmarkFolderNameTaken`, `builtInBookmarkFolderReadonly`,
  `bookmarkFolderConflict`.

### Эндпоинты

```
GET    /bookmark-folders                     → { items: BookmarkFolder[], hasNew }
POST   /bookmark-folders                     { name, icon, color, trackUpdates }
PATCH  /bookmark-folders/:id                 { name?, icon?, color?, trackUpdates? }
PUT    /bookmark-folders/order               { ids: string[] }
DELETE /bookmark-folders/:id?moveTo=<id>     без moveTo — закладки папки удаляются

GET    /bookmarks?folderId=&sort=&direction=&query=&page=
       direction: asc | desc, без него — естественное для sort (даты — desc, алфавит — asc)
       → { items: BookmarkItem[], page, total }
         BookmarkItem: titleId (цель клика), sourceId, name, coverUrl, folderId,
         progress (номер главы + всего глав) | null, newChaptersCount,
         otherSources: { sourceId, titleId }[], availability
POST   /bookmarks/lookup     { titleIds }    → { [titleId]: folderId } — метки на карточках
POST   /bookmarks/restore    { rows }        — «Вернуть» после удаления

GET    /titles/:titleId/bookmark             → { folderId | null }
PUT    /titles/:titleId/bookmark             { folderId } — добавить или перенести группу
DELETE /titles/:titleId/bookmark             → { rows } — удалённые строки для restore
POST   /titles/:titleId/bookmark/visit       → { newChapterIds } — до обнуления; фронт подсвечивает их
```

- `PUT /titles/:titleId/links` (подтверждение связи) получает необязательный `bookmarkFolderId`.
  Если оба тайтла в закладках в разных папках, а поля нет, ответ — `409 bookmarkFolderConflict`
  с обеими папками. Фронт показывает модалку и повторяет запрос.
- `PUT /titles/:titleId/progress` обновляет `visitedAt` группы.
- `GET /bookmark-folders` отдаёт `hasNew` для точки в шапке и счётчики для вкладок и профиля.

### Удаление аккаунта

Таблицы `bookmark_folders` и `bookmarks` удаляются каскадом от `users`. Общие таблицы снимков не
трогаются. Снимки тайтлов, которых больше нет ни в одних закладках, крон чистит раз в сутки.

## Крайние случаи

| Случай                                                                   | Что видит пользователь                                                             |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------- |
| Загрузка `/bookmarks`                                                    | `BookmarksSkeleton`: вкладки и сетка карточек в текущем `viewMode`                 |
| Ошибка списка                                                            | Глобальный тост от `QueryClientProvider`, на месте списка — пустое состояние       |
| Нет ни одной закладки                                                    | `EmptyState`: «Здесь будут ваши закладки» и как добавить, кнопка «Открыть каталог» |
| Пустая папка                                                             | `EmptyState`: «В этой папке пока пусто»                                            |
| Поиск ничего не нашёл                                                    | `EmptyState`: «Ничего не найдено» и кнопка «Сбросить»                              |
| Закладок меньше страницы                                                 | Пагинации нет (`ListPagination` прячется сам)                                      |
| Длинное название тайтла                                                  | Обрезка в 2 строки, как в каталоге                                                 |
| Длинное название папки (32)                                              | Во вкладке — обрезка с многоточием, полностью в `title`                            |
| Нет отметки прогресса                                                    | Вместо «Гл. N из M» — число глав или `<Mdash />`                                   |
| Источник выключен / лежит / тайтл пропал, других источников в группе нет | Карточка приглушена, пометка `BOOKMARK_AVAILABILITY`                               |
| Источник цели лёг, но в группе есть другой                               | Цель — следующий доступный источник группы                                         |
| Новых глав 0                                                             | Пометки нет                                                                        |
| Папка без «Следить за обновлениями»                                      | Пометки нет, в точке шапки не участвует                                            |
| Тайтл 18+ при `hideAdultTitles`                                          | Обложка под `HiddenCoverOverlay`, как в каталоге (см. «Открытые вопросы»)          |
| 20 своих папок                                                           | «Новая папка» неактивна, тултип с лимитом                                          |
| Имя папки занято                                                         | Ошибка `validate` под полем                                                        |
| Удаление папки с тайтлами                                                | Модалка `danger` с выбором «перенести в…» или «убрать из закладок»                 |
| Две копии в разных папках при подтверждении связи                        | Модалка `warning` выбора папки                                                     |
| Отмена связи                                                             | Две отдельные закладки в одной папке                                               |
| Офлайн                                                                   | Как остальные страницы сейчас: общий офлайн-слой, правки без сети не проходят      |
| Крон ещё не проверял тайтл                                               | Пометки нет. Первый снимок — базовый, все 1093 главы новыми не станут              |

## Дизайн

- **Где живёт:**
  - страница `/bookmarks` (`pages/Bookmarks`);
  - `Select` папки на странице тайтла (`TitleImageSection`, на месте заглушки);
  - `ActionIcon` + `Menu` в `ReaderControls`;
  - вкладка «Закладки» в `pages/Settings` (отложенная вкладка N4 «Библиотека» появляется под
    названием «Закладки»);
  - блок в `ProfileStatistics`;
  - метка на `TitleCard` (`entities/title/card`);
  - точка новой главы у узла в `ChapterItem`;
  - точка на иконке шапки и пункте футера.
- **Слои:**
  - действие «в закладки» (`Select`, `Menu`, хуки запросов) — `features/bookmark`: у него три
    потребителя;
  - метка на карточке — `entities/title/markers`.
- **Вкладки `/bookmarks`** — массив `TABS` в `useMemo`, как в `pages/Settings`. Полоса
  прокручивается вбок на мобилке. Активная вкладка лежит в `?folder=<id>`.
- **Модалки:**
  - «Новая папка» / «Переименовать» — `neutral`, иконка папки;
  - «Удалить папку» — `danger`, иконка корзины;
  - «Выбор папки при склейке» — `warning`, иконка закладки.
  - Все три добавляются в таблицу модалок `11-ui-decisions.md`.
- **Тексты:**
  - числа — моноширинным: счётчики во вкладках, «+N» у иконки источника;
  - «Гл. 1090 из 1093» — фраза, поэтому Golos Text. Номера внутри неё — моноширинным
    (`NumericMeta`), как в мета-строке карточки.
- **Мобилка и десктоп:**
  - на мобилке вкладки скроллятся, сортировка и переключатель вида переносятся под поиск,
    карточки — в `viewMode`;
  - на десктопе то же шире, вход через иконку шапки.
- **Обе темы:** цвета папок — только из Mantine-палитры через CSS-переменные.
- **Выбранный вариант** — **C10h + U3a + T2 + A1 + I1 + E + S4 + R2c + K4a + N3 + D1 + F1 + P2 +
  G1 + M1d** (песочница `/playground/bookmarks`, подробно —
  [11 — Закладки](../11-ui-decisions.md#закладки)). Новое — точка без числа на всём пути: шапка
  (D1) → вкладка папки (T2) → конец первой строки названия (C10h) → узел главы (N3). Где папку
  выбирают из списка (S4, меню читалки, M1d), выбранная красится в её цвет, а не в акцент.
- **Действия на карточке (Q4, 2026-10-07)** — меню «⋯» в мета-строке: другие источники,
  «Перенести в папку» модалкой, «Убрать из закладок» с «Вернуть»; у иконки источника — тихий «+N».
  См. [11 — Действия на карточке закладки](../11-ui-decisions.md#действия-на-карточке-закладки-q4).

## Отличия реализации от плана

- **Конфликт папок у других пользователей.** Связи глобальны и подтверждает их персонал, так что
  модалка при подтверждении решает конфликт только у подтверждающего. У остальных копии группы
  остаются в разных папках: `GET /titles/:id/bookmark` отдаёт `conflict`, и при следующем открытии
  тайтла пользователя спрашивают той же модалкой M1d (кнопка «Сохранить»). До выбора группа лежит в
  папке самой свежей строки — так её считают вкладки и список.
- **Тело 409** папок не несёт: в `ApiError` под них нет места. После 409 фронт сам запрашивает
  закладки обеих сторон.
- **Снимок в строке закладки** шире: кроме названия и обложки — `contentRating` (бейдж 18+ и
  размытие) и `type` (строка типа в списке). Обложка хранится сырым адресом и подписывается при
  чтении — подпись прокси живёт час.
- **`TitleLinksModule`.** `TitleLinksService` вынесен из `MatchesModule` в свой модуль, иначе
  `MatchesModule` и `LibraryModule` импортировали бы друг друга.
- **Внешний ключ закладки на папку** — `no action`, а не `restrict`: проверка в конце оператора не
  мешает каскаду от `users`.
- **Дотяжка** пишет снимок не чаще раза в 5 минут — список глав грузится отдельно для каждой
  ветки. Визит и крон пишут всегда. Визит сначала обновляет снимок, потом считает новые главы и
  только потом засчитывается.
- **Крон** проверяет не только закладки, но и отметки чтения тех же групп: карточка считает главы
  по источнику свежей отметки, а он может быть не в закладках. Суточная чистка держит снимки, на
  которые ссылаются закладки или отметки.
- **`otherSources`** знает только те копии, чей `titleId` где-то сохранён: в строках закладок или
  в снимках глав (снимок пишется при открытии тайтла).
- **Уникальность названия папки** проверяется против названий встроенных на всех языках
  интерфейса, а не только на языке пользователя.
- **`POST /bookmarks/lookup`** принимает до 1000 id — бесконечная прокрутка каталога шлёт все
  показанные карточки.

## Отвергнутые идеи

- **Статус + свои категории-метки (много на тайтл).** Выбрана одна папка на тайтл, как на
  MangaLib: проще модель и UI, нет двух параллельных осей.
- **Только встроенные статусы.** Нужны свои папки.
- **Встроенные папки как обычные, с удалением и переименованием.** Встроенные неприкасаемы:
  на них опираются импорт со статусами и значения по умолчанию.
- **Dexie local-first.** Приложение уже требует вход, прогресс на сервере. Локальное хранение
  дало бы только синхронизацию и конфликты.
- **Закладка на копию тайтла без склейки по группе.** Противоречит решению по импорту с источника
  (копия добавляется к существующей закладке) и отметкам прогресса группы.
- **Закладки на страницу внутри главы.** Место чтения уже хранит прогресс.
- **Автопереходы** («Читаю» при начале, «Прочитано» в конце, возврат при новых главах). Папку
  меняет только пользователь.
- **«Новые» = непрочитанные после отметки.** Выбрано «вышедшие с последнего визита».
- **Проверка обновлений только при открытии `/bookmarks`.** Медленный первый заход, ничего не
  узнаём без визита, не годится для будущего колокольчика.
- **Сайдбар папок или один список с фильтром.** Выбраны вкладки.
- **Управление папками прямо на `/bookmarks`.** Полное управление — в настройках, на странице
  только ссылка и быстрое создание.
- **Модалка на «Убрать из закладок».** Действие обратимо через «Вернуть» в тосте.
- **Всегда меню выбора источника при клике.** Лишний клик в большинстве случаев. Меню доступно по
  иконке источника.
- **«Побеждает свежая правка» при склейке.** Пользователь предпочёл, чтобы его спрашивали.
